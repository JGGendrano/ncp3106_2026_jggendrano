Professional Pathways

Career & Job Opportunities

Discover dynamic career pathways in Computer Engineering—from designing embedded hardware to building modern AI algorithms and cloud networks.

Computer Engineer

Integrates computer science and electrical engineering to research, design, develop, and test computer systems, circuit boards, and integrated components.

System Design FPGA VHDL
Key Work: Hardware-software integration, system testing, and digital circuit design.
Embedded Systems Engineer

Develops custom firmware and low-level software that runs directly on embedded microcontrollers within automotive, medical, and consumer devices.

C/C++ RTOS Microcontrollers
Key Work: Writing bare-metal code, real-time operating system control, hardware debugging.
IoT Engineer

Architects end-to-end connected systems by bridging sensor hardware with wireless protocols and cloud telemetry analytics.

MQTT ESP32 AWS IoT
Key Work: Wireless network integration, smart sensor nodes, cloud dashboard sync.
Software Engineer

Designs, codes, tests, and maintains scalable web applications, operating tools, desktop systems, and software platforms.

JavaScript Python Git
Key Work: Full-stack development, API development, software maintenance.
Hardware Engineer

Focuses on designing and testing physical computer hardware components like processors, circuit boards, memory systems, and routers.

PCB Layout CAD Verilog
Key Work: Circuit schematic creation, PCB routing, physical hardware testing.
Network Engineer

Plans, constructs, and manages local and wide area communication networks to ensure continuous, high-speed data flow.

Cisco TCP/IP Subnetting
Key Work: Router/switch configuration, network optimization, troubleshooting infrastructure.
Cybersecurity Engineer

Safeguards enterprise network infrastructure and firmware systems against cyber threats, unauthorized access, and vulnerabilities.

Linux Pen Testing Cryptography
Key Work: Threat analysis, security audits, firewall enforcement, security patch deployment.
AI / ML Engineer

Researches and trains machine learning models to enable automated reasoning, predictive modeling, and intelligent hardware automation.

PyTorch TensorFlow OpenCV
Key Work: Neural network training, model optimization, computer vision development.
Robotics Engineer

Combines mechanical control, electronic sensors, and motor driver code to build autonomous robotic platforms and manufacturing automation.

ROS Actuators Control Theory
Key Work: Kinematics, autonomous navigation setup, sensory feedback integration.
